## Projects

- **[elpris-kubernetes-autoscaling](https://github.com/Keandre-Git1/elpris-kubernetes-autoscaling)**: An electricity price app in Flask that I containerized and ran in Kubernetes. The HPA scaled it from 1 to 5 pods in a k6 load test with 0% failed requests. GitHub Actions runs ruff and pytest and pushes the image to GHCR, tagged with the commit SHA.
- **pipeline-till-prod** (private repo): CD for the app above. A self-hosted runner deploys the tested image with Ansible and rolls back automatically if the health check fails.
- **Ansible course project** (private repo): Nginx, Gunicorn, Flask and MariaDB on three Ubuntu servers, set up with one command using roles, Vault, Jinja2 and a dynamic inventory.
